# Feature requests — from browser playtest (2026-08-23)

1. **Highlight the last two moves.** Clearly mark the most recent human move and
   the most recent AI move on the board, so it's obvious what just happened.

2. **Turn the score log into a real UI component.** Replace the plain "You
   scored / AI scored" text with per-event rows, subtly tinted by scoring player.
   Clicking a row highlights the tile and placement that earned the points.

3. **Meeple hover breakdown.** Hovering a placed meeple highlights every tile in
   the feature it claims and shows: current running score, and potential score if
   the feature is completed.

4. **Reset-view button.** A control to recentre and reset pan/zoom of the board.
